## SCREEN RECORDING CHECKLIST

- [ ] Clear browser window (close unnecessary tabs)
- [ ] Full-screen browser mode
- [ ] Smooth scrolling enabled
- [ ] Good screen resolution (1080p minimum)
- [ ] Test navigation flow before recording
- [ ] Have script ready (printed or second screen)
- [ ] Quiet environment for clean audio
- [ ] Test microphone quality

---

## POST-PRODUCTION NOTES

1. **Audio Sync**: Ensure narration matches screen actions
2. **Transitions**: Add smooth fades between major sections
3. **Music**: Optional subtle background music (keep low volume)
4. **Export**: MP4, H.264, 1080p or higher
5. **Duration**: Keep final video between 3-4 minutes
