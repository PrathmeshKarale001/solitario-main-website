# Solitario - Lab Grown Diamond Jewellery Website

A modern, luxury website for Solitario - India's most loved new-age diamond jewellery brand featuring lab-grown diamonds and sustainable luxury.

## Features

- 🎨 Modern, luxury design with scroll animations
- 💎 Product showcase with category filtering
- ♻️ Focus on sustainable, lab-grown diamonds
- 📱 Fully responsive across all devices
- ⚡ Built with Next.js 14+ and TypeScript
- 🎭 Smooth animations with Framer Motion
- 🎯 SEO optimized

## Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
